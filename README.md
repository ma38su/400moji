# 四百字

[![Deploy to GitHub Pages](https://github.com/ma38su/400moji/actions/workflows/deploy-pages.yml/badge.svg)](https://github.com/ma38su/400moji/actions/workflows/deploy-pages.yml)

20字×20行の縦書き原稿用紙で、作文の下書きを作るためのシンプルなWebアプリです。

## 公開サイト

**[四百字を開く](https://ma38su.github.io/400moji/)**

## できること

- 原稿用紙をクリックして縦書き入力
- 原稿用紙のマスをドラッグして文字を範囲選択し、コピー・カット・削除・貼り付け
- 原稿用紙の右クリックメニューからコピー・カット・ペースト・削除・すべて選択
- マスの上半分・下半分をクリックして文字の前後へキャレットを移動
- 原稿用紙ビューと、選択・コピー・貼り付けがしやすい縦書き編集ビューの切り替え
- `↑`・`↓`キーで空白を含めて1文字ずつ、`←`・`→`キーで隣の縦列へカーソル移動
- `Shift`＋矢印キーで縦書きの移動方向に沿って選択範囲を拡張・縮小
- 20字×20行（400字詰め）の複数ページ表示
- 改行すると次の縦列の先頭へ移動
- `。`と`、`を縦書き向けの位置に表示
- 行末の句読点を直前の文字と同じマスに表示
- 使用マス数、「何枚目・何行目の何マス目まで」進んだか、入力文字数の確認
- ブラウザへの自動保存
- Undo・Redo（画面ボタン、`Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z`）
- 半角の丸括弧 `()` を縦書き向けの全角 `（）` に自動変換
- ファイル名を付けた複数原稿の保存・切り替え・複製（同名ファイルは作成不可）
- TXT・JSON形式での書き出し
- TXT・JSON形式で保存した原稿の読み込み
- 原稿全ページをA4横向きの原稿用紙スタイルで印刷

## 使い方

1. 公開URLを開きます。
2. 上部のファイル名を必要に応じて変更します。
3. 原稿用紙をクリックして作文を入力します。
4. 作文を書き終えたら、右上の「ファイル」から「TXTを書き出す」を選びます。

入力内容はファイルごとに同じブラウザへ自動保存され、次回アクセス時に復元されます。左サイドバーの「原稿ファイル」でファイルを切り替えられます。「ファイル」メニューから新規作成と複製ができます。同じ名前のファイルは作成できません。

> [!IMPORTANT]
> ブラウザの自動保存だけに頼らず、作文を書くたびにTXTまたはJSONファイルを書き出してください。ブラウザのサイトデータを削除すると、自動保存した原稿が失われる可能性があります。

## ローカルで動かす

Node.js 20.19以上を用意してください。

```sh
npm install
npm run dev
```

ターミナルに表示されるURL（通常は `http://localhost:5173`）をブラウザで開きます。

## ビルド

```sh
npm run build
```

本番用ファイルは `dist/` に生成されます。

## GitHub Pagesへの公開

`main` ブランチへpushすると、GitHub Actionsが自動的にビルドし、GitHub Pagesへデプロイします。

手動で再デプロイする場合は、GitHubの「Actions」から「Deploy to GitHub Pages」を選び、「Run workflow」を実行します。

## データの扱い

- 原稿本文はサーバーへ送信しません。
- 複数ファイルの本文、ファイル名、表示ページをブラウザの `localStorage` に保存します。キャレット位置は保存しません。
- TXTは作文本文だけ、JSONはタイトルや表示ページなどを含むデータを書き出します。

## 現在の制限

- 自動保存した原稿は、保存したブラウザと端末でのみ利用できます。
- 行末の句読点付近では、画面上のカーソル位置と実際の文字位置が分かりにくい場合があります。

大切な作文は、必ずTXTまたはJSONでも保存してください。
